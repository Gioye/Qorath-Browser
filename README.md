# Qorath Browser
A Custom Python-Powered Open Source Browser

## Python Libraries
threading, tkinter, ttk, webview, PIL, Image, ImageTk, requests, io, BytesIO, speech_recognition
### Installing Those Libraries
Use This Command: `pip install pywebview pillow requests SpeechRecognition` 

If you're On Linux, You also need to use: `sudo apt install python3-tk`
